## 📖 About / درباره

English:  
This repository contains all the network simulation files I have created during my CCNA and CCNP studies. Each file represents a specific scenario, protocol implementation, or troubleshooting exercise.

فارسی:  
این ریپازیتوری شامل تمام فایل‌های شبیه‌سازی شبکه‌ای است که در طول دوره‌های CCNA و CCNP ایجاد کرده‌ام. هر فایل نمایانگر یک سناریوی خاص، پیاده‌سازی یک پروتکل یا تمرین عیب‌یابی است.

## 🚀 How to Use / نحوه استفاده

English:  
1. Download the .pkt file you need.  
2. Open it with Cisco Packet Tracer (version 8.x or higher).  
3. Run the simulation and observe the network behavior.

فارسی:  
۱. فایل .pkt مورد نظر را دانلود کنید.  
۲. آن را با پکت‌تریسر نسخه ۸ یا بالاتر باز کنید.  
۳. شبیه‌سازی را اجرا کرده و رفتار شبکه را مشاهده کنید.
